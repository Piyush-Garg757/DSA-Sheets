 starting node is called root node

 ending node is called leaf node 

 a particular node and the tree below it which it forms as a root is called subtree

 for a particular node, its parent node , grand parent node, grand grand parent node and so on are called its ancestors


 Types of binary trees:

 1. Full binary tree - either has 0 or 2 children 

          1
         / \
        2   3
           / \
          4   5
         / \
        6   7
        
 2. Complete binary tree - all levels are completely filled except the last level and the last node has all nodes in left as possible

        1
       / \
      2   3
     / \
    4   5
 This is a Complete binary tree as all levels have all possible children except the last node which is completely fine 

        1
       / \
      2   3
     / \ /
    4  5 6    This is fine too

        1

 3. Perfect binary Tree - all leaf nodes are at the same levels

          1. Inorder Traversal (Left Root Right)
          2. Preorder Traversal (Root Left Right)
          3. Postorder Traversal (Left Right Root)
